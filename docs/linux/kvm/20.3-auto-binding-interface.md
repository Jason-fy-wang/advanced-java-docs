**1. Keep VM XML like this**
vm config as below:
```xml
<interface type='bridge'>
  <mac address='02:00:00:00:00:11'/>
  <source bridge='br-int'/>
  <virtualport type='openvswitch'/>
  <model type='virtio'/>
</interface>

```

**2. Create a VM-to-OVN-port mapping**
On each KVM host:
```bash
sudo mkdir -p /etc/libvirt/hooks
sudo vi /etc/libvirt/hooks/ovn-port-map.conf
```

Example:

```bash
name1 02:00:00:00:00:11 vm-name1-port
node1 02:00:00:00:00:12 vm-node1-port
node2 02:00:00:00:00:13 vm-node2-port
```

Only include VMs that run on that host.

**3. Create the libvirt hook**


```
sudo vi /etc/libvirt/hooks/qemu
```

Content:

```bash
#!/usr/bin/env bash
set -euo pipefail

VM_NAME="$1"
ACTION="${2:-}"
PHASE="${3:-}"

MAP_FILE="/etc/libvirt/hooks/ovn-port-map.conf"

# Run only after the VM has started, when libvirt has created the vnet/tap device.
if [ "$ACTION" != "started" ] || [ "$PHASE" != "begin" ]; then
  exit 0
fi

[ -f "$MAP_FILE" ] || exit 0

while read -r vm mac iface_id; do
  [ -z "${vm:-}" ] && continue
  [[ "$vm" =~ ^# ]] && continue
  [ "$vm" = "$VM_NAME" ] || continue

  tap="$(
    virsh domiflist "$VM_NAME" |
      awk -v mac="$mac" 'tolower($5) == tolower(mac) { print $1; exit }'
  )"

  if [ -z "$tap" ]; then
    logger -t libvirt-ovn-hook "No tap found for VM=$VM_NAME MAC=$mac"
    exit 1
  fi

  ovs-vsctl set Interface "$tap" external_ids:iface-id="$iface_id"
  ovs-vsctl set Interface "$tap" external_ids:attached-mac="$mac"
  ovs-vsctl set Interface "$tap" external_ids:vm-id="$VM_NAME"
  ovs-vsctl set Interface "$tap" external_ids:iface-status=active

  logger -t libvirt-ovn-hook "Bound VM=$VM_NAME tap=$tap iface-id=$iface_id mac=$mac"
done < "$MAP_FILE"
```

Make it executable:

```bash
sudo chmod +x /etc/libvirt/hooks/qemu
sudo systemctl restart libvirtd || sudo systemctl restart virtqemud
```
**4. Test**

Restart a VM:

```bash
virsh shutdown vm-a
virsh start vm-a
```

Check the new tap:

```bash
sudo ovs-vsctl list-ports br-int
virsh domiflist vm-a
```

Then check whether the hook set the right OVN binding:

```bash
sudo ovs-vsctl list Interface vnet0
```

Use the actual tap name from `virsh domiflist`. You should see:

```text
external_ids : {attached-mac="02:00:00:00:00:11", iface-id="vm-a-port", iface-status="active", vm-id="vm-a"}
```


**5. Stop assigning IP manually**

The port automation fixes the host side. For the guest IP, use either static IP inside the VM or OVN DHCP.

For a quick static guest config on Ubuntu with netplan:

```yaml
# /etc/netplan/50-cloud-init.yaml
network:
  version: 2
  ethernets:
    ens3:
      addresses:
        - 10.30.0.11/24
      routes:
        - to: default
          via: 10.30.0.1
      nameservers:
        addresses:
          - 8.8.8.8
```

Apply inside the VM:

```bash
sudo netplan apply
```
