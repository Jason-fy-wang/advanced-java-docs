After create kvm with ovs base on [[20-kvm-ovn-sdn-network]],  every time you restart kvm, we need manual bind the new vnet interface to ovs.

> Auto bind vnet to OVN

Libvirt default use `Linux-bridge`,  so we need define OVS interface and belong to OVN directly.

```xml
## ovn-lan.xml
<network>
	<name>ovn-sdn-lan</name>
	<forward mode='bridge'/>
	<bridge name='br-int'/>
	<virtualport type='openvswitch'>
	</virtualport>
</network>
```

```shell
# define interface
virsh net-define ovn-lan.xml
virsh net-start ovn-sdn-lan
virsh net-autostart ovn-sd-lan
```

```xml
# edit vm interface
# virsh edit vm
<interface type='bridge'>
<source bridge='br-int' />
<virtualport type='openvswitch' />
<model type='virtio' />
</interface>

```
