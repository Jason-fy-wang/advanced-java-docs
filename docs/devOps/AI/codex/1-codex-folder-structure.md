personal config:
```shell
~/.codex/config.toml  The main configuration file for setting like default models, providers and approval policies.

~/.codex/agents/  strores personal, global subagent definitions 

~/.codex/sessions/  Store history of previous interactions in JSON lines format , allowing session resumption

~/.codex/rules/  store custom rules, such as default.rules, that define how Codex handles specific commands.
```


Project config:
```text
my-project/ 
	├── .codex/ 
	│ └── config.toml  # Project-specific settings (model, constraints) 
	├── .agents/ 
	│     └── skills/      # Reusable behavior packages 
	│         ├── database-handler/ 
	│                 └── SKILL.md # Skill instructions, name, description 
	│         └── python-testing/ 
	│                 └── SKILL.md 
	├── AGENTS.md       # Mandatory: Repo-level instructions for Codex 
	├── README.md # Human-readable documentation 
	└── src/
	       └── service/
			 └── AGENTS.override.md        # overrite AGENTS.md
```


example config.toml
```shell
[model]
# Default model to use for this project
name = "gpt-5-codex"

[agent]
# Automatically create backups in .agents/backups
sandbox_mode = "workspace-write"

[rules]
# Path to extra instruction files
extra_instructions = ["./docs/ai-guidelines.md"]
```


skills/git-commit-writer/SKILL.md
```shell
---
name: GitCommitWriter
description: Formats commit messages according to conventional commits.
---

# GitCommitWriter
When I ask you to commit, follow these rules:
1. Use the format: `<type>(<scope>): <description>`
2. Types: feat, fix, docs, style, refactor, test, chore.
3. Keep descriptions under 50 characters.
```

AGENTS.md (locate in root folder)
```shell
# AGENTS.md 
## General Rules 
- Always use TypeScript with strict mode. 
- Use `npm` for package management. 
- Do not modify files in the `/legacy` directory. 

## Testing 
- Run `npm test` before submitting changes. 
- Ensure 90% coverage for new components. 
  
## PR Strategy 
- Squash commits. 
- Add `[Agent]` prefix to PR titles generated by me.

```
